# Plot 3-Panel Sensor Gas MQ-135 & Fusion Index Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambahkan estimasi konsentrasi gas (`gas_ppm`) dan memperbarui fungsi plot `sitl.py` menjadi 3 panel (PM-proxy & FI, Sensor Gas MQ-135 `ppm` sebenarnya vs estimasi + skor `g`, serta Duty & State).

**Architecture:** `core.Firmware._gas_update()` menyimpan nilai `self.ppm` (dan mengembalikannya sebagai `gas_ppm` di `step()`). `sitl.py` mencatat `gas_true` (`plant.gas_ppm`) dan `gas_ppm` (`tel["gas_ppm"]`) ke dalam `rows`, lalu `make_plot()` menggambar 3 subplot vertikal dengan sumbu ganda (`twinx`) pada panel gas.

**Tech Stack:** Python 3, `matplotlib`, C++ (`karhutla_esp32.ino` untuk sinkronisasi).

**Spec:** `docs/superpowers/specs/2026-11-06-gas-plot-design.md`

## Global Constraints

- Bahasa komentar dan label grafik wajib dalam **Bahasa Indonesia**.
- Perilaku state machine, nilai `g`, `fi`, dan `duty` tidak boleh berubah; `python sitl.py --scenario all` harus tetap lulus semua.
- Gunakan label **"PM-proxy"** pada keterangan sumbu/judul PM.

## Review Focus

- Saat `self.r0 is None` (30 sampel pertama kalibrasi udara bersih), `self.ppm` bernilai `K.MQ_ATM_PPM` (400.0 ppm), dan saat `failsafe` di-reset, `self.ppm` di-reset kembali ke `K.MQ_ATM_PPM`.
- Legenda pada Panel 2 (yang menggunakan `ax2` dan `ax2_g = ax2.twinx()`) harus digabungkan agar kurva `ppm` dan kurva `skor gas g` keduanya tampil di satu kotak legenda yang rapi.
